Tower teleport coordinates used by the "Teleport to Tower" dropdowns:

* `botw-towers.txt` (BotW) and `totk-towers.txt` (TotK) ship here.
* To override, put files in `<user data>/towers/` (they take priority). A file belongs to BotW if its name contains `botw`, `breath` or `sheikah`, and to TotK if it contains `totk`, `tears` or `skyview`.

One tower per line: the tower's name, then X Y Z (the last three numbers on the line are used), as shown in the save editor's Position boxes. Even the full manual instruction .txt files work as-is.
